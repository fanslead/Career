# 前端交互原型与体验审查

原型审查：2026-10-14。已生成可点击原型，并据此修订方案。2026-10-15 已另行建立生产 React 前端并完成首个本地闭环，当前实测见 [18](18-production-m1-delivery.md)；本文保留原型审查时的范围与设计证据，不用原型状态代替生产状态。

打开 [交互原型](prototype/index.html) 或 [页面图册](prototype/gallery.html)。所有示例和操作均为本地模拟。原型浏览器验证不替代 [08](08-delivery-and-validation.md) 的生产门槛，也不扩大 P0 已验证范围。

## 1. 评审范围与视觉方向

保留工作台、项目、团队、资料、设置五项一级导航。办公/研发/经营是工作模式，不是三个独立系统；切换只影响建议与模板，不能改变现有任务状态。

视觉采用浅色蓝灰底、蓝青强调色，侧栏和顶栏使用轻量半透明材质；正文和表单保持不透明。工作台先呈现交办与待处理事项，不用虚拟办公室或虚构完成百分比占据主要空间。正文常规 14–16px，次要说明 12–13px；状态同时有文字与颜色。

桌面采用固定侧栏和宽内容区，任务详情采用主要内容与信息侧栏。窄屏将信息侧栏移到下方，主导航变为可关闭抽屉；关键动作不要求水平拖动。看板提供列表替代。

## 2. 页面与交互覆盖

| 一级入口 | 已生成的页面/交互 | 核心状态与处理 |
| --- | --- | --- |
| 工作台 | 交办输入、附资料、选负责人、模式模板、待处理、最近任务、成果、对话历史 | 草稿保留；待处理从各任务状态汇总；已处理事项退出收件箱 |
| 首次使用 | 空工作台、工作区位置、模型连接/测试、返回原草稿、计划确认 | 不先建组织；连接失败保留非敏感输入；模型与范围检查完成后再派发 |
| 任务 | 目标/验收、责任人与执行者、一次分工、活动、成果、对话、改派 | 执行、暂停请求、停止中、已暂停/停止、交接、受阻、失败、恢复、冲突 |
| 三类确认 | 计划、工具许可、固定版本验收 | 三类标题、对象和后果不同；打开页面不修改任务业务状态 |
| 外部动作 | 收件人/正文/附件预览、允许一次/有限流程、退回、拒绝、查询结果、记录结论 | 内容变化使旧许可失效；未知效果不盲重试；结论须有依据；接受不等于送达 |
| 成果 | 报告阅读、来源定位、研发差异/检查、发送交付记录、下载、版本历史、退回 | 成果版本固定；执行成功不等于任务完成；新版本重新验收 |
| 项目 | 项目列表、新建、目标、任务看板/列表、成果、依赖说明、汇报偏好 | 空项目先提供第一项任务入口；任务与成果从所属项目汇总 |
| 团队 | 成员列表、职责/能力编辑、新增、暂停接单、归档与交接 | 活跃任务先处理；责任切换前等待旧执行者停止或隔离 |
| 资料 / 知识 | 文件选择、导入、解析失败、示例重试、引用预览、索引代次重建 | 错误不能伪装成空内容；引用绑定版本与位置；候选构建期间旧代次继续可用 |
| 资料 / 记忆 | 候选来源/范围审核与发布/拒绝、私有/共享、版本、使用记录、更正、共享预览、归档、遗忘范围 | 归档仍可搜索；遗忘停止未来注入；在途和既有外发边界说明 |
| 设置 / 模型 | 四协议选择、连接测试、知识检索模型与维度 | 连接测试/保存分离；能力与错误可见；修改参数后旧测试结论失效 |
| 设置 / 工具 | 内置能力、连接与技能包、安装、授权、范围、撤销 | 安装不自动授权；新增工具需单独检查 |
| 设置 / 邮箱与预算 | SMTP、通讯录/默认联系人、频率/静默时段、目标预览、连接测试、独立试发；费用/调用/时长/并发限额 | 测连接不发信；货币单位显式；失败保留输入 |
| 设置 / 自动化 | 规则启停、执行时间、时区、漏跑策略 | 跳过/合并/有上限补跑；实际发生实例去重留在生产合同 |
| 设置 / 工作区与访问 | 备份周期/保留数、诊断字段预览、新目录恢复、缺密钥、配对/登录/退出、会话撤销、API/Webhook 范围、账号恢复 | 不覆盖活动工作区；无密钥不创建新密钥覆盖；生产认证另行实现 |

账号恢复、通知通讯录、API/Webhook 范围、索引重建与候选发布均已提供可点击的本地流程；对话历史可搜索示例记录。原型覆盖完整一级页面和主要深层流程，但真实凭据签发、权限集合/有效期、全量检索分页与长时间重建进度仍在相应生产工作包实现和验收。

## 3. 按原型走查后修正的规则

| 发现的问题 | 原型处理与方案补充 | 实施责任 |
| --- | --- | --- |
| 打开成果或许可页就改变状态，容易把“看过”误当“处理过” | 导航只改变所选对象；只有确认命令和权威回执改变业务状态 | W01/W04/W09 |
| 邮件许可与报告验收共用一个页面状态，处理 A 会覆盖 B | 按对象身份保存任务状态；收件箱、项目和团队由同一对象缓存汇总；异步回执绑定发起对象，不能写到新选择 | W04/W08/W09/W13 |
| 计划页出现前就显示运行中 | 未确认计划保持草稿/待确认；确认被服务端接受后再显示排队或执行；待确认不能经其他入口直接继续；等待派发时不展示完成活动或费用 | W04/W07/W09 |
| 修改连接后仍可沿用旧测试结果，失败退出会丢字段 | 连接草稿与测试结论分开；地址/协议/模型/密钥变化使旧结论失效，非敏感字段返回时保留 | W06/W09/W14 |
| 离线只禁用部分按钮，刷新又误报连接正常 | 统一命令可用性；直到补齐权威快照前保持只读，打开弹窗也不能绕过；未发出的草稿可本地保存 | W08/W09 |
| 键盘切页签与重绘丢焦点，手机只剩无名称图标 | 保留触发控件焦点；导航后落在页面标题；弹窗关闭回触发处；窄屏抽屉有关闭入口、焦点约束和可访问名称 | W09/W20 |
| 全部任务导向项目，独立草稿难以找回 | 总览包含所有任务；草稿返回同一计划，项目归属明确且不带入下一项独立任务 | W04/W09 |
| 访问设置仅写“当前对象”，恢复后同时出现两个当前会话 | 授权预览列出具体任务、成员和项目，记录固定目标；恢复/配对后仅新会话标为当前 | W06/W09/W14 |
| 页面出现过多底层状态名与不一致示例 | 用户可见标签中文化，技术标识折叠；成员负载与任务状态一致，范围预览使用实际成员数 | W09/W13/W16 |

这些规则已回填 [07 界面](07-ux-and-reporting.md)、[11 通信](11-frontend-runtime-protocol.md)、[14 生产方案](14-production-implementation-plan.md)和 [15 工作包](15-production-work-packages.md)。

## 4. 六条必须走通的生产用户旅程

1. **交办第一项任务**：先输入 → 确定工作区 → 测模型 → 失败修复后仍保留草稿 → 对齐目标/成果/范围 → 开始；不要求先建岗位。
2. **可控外发**：检查固定目标/正文/附件 → 有限许可 → 收到明确回执或进入待核对 → 查询/带依据记录；没有证据时不重发。
3. **可检查交付**：执行结束 → 查看固定版本与证据 → 退回新版本 → 再验收 → Task 完成；未运行检查仍然明确。
4. **可恢复接管**：请求暂停/停止 → 收到确认 → 保留成果；改派时先交接、停旧写者、核对结果，无法确认就冻结相关资源。
5. **可治理记忆**：导入与引用 → 候选发布/更正 → 私有共享预览 → 归档或遗忘；范围、版本、在途影响可查，旧副本不得继续注入。
6. **跨页面一致**：长任务运行期间切模式/项目、断线重连、多窗口冲突；选择和草稿保留，旧回包不覆盖新对象，列表和详情状态一致。

## 5. 验证口径

原型级浏览器操作记录见 [validation.json](prototype/validation.json)。本次验证包括首次任务与连接失败返回、计划确认、任务独立状态、暂停确认、断线刷新与重连、未知发送结果、固定版本验收、成员编辑、知识索引切换、记忆候选发布、通讯录、账号恢复、备份策略/诊断预览，以及 320px/390px 布局和键盘焦点。

这里只验证浏览器中呈现的本地模拟行为。真实后端的鉴权、授权、幂等、事件补齐、取消与进程停止、旧执行隔离、实际上传/解析、模型费用、外部回执、备份、密钥及跨平台均未在本轮执行。200% 浏览器缩放、完整屏幕阅读器、真实移动浏览器与软键盘、长文档极限规模仍是待跑门槛，不能由窄窗口截图代替。

## 6. 交付与使用顺序

先用 [图册](prototype/gallery.html)看页面关系，再在原型的「页面与流程总览」走六条旅程。方案采用这次原型修正后的交互合同，但保留真实用户试用反馈入口。进入正式前端开发后，先实现任务闭环与统一对象缓存，再接入团队、资料和设置；每接入一类真实命令都复跑对应旅程。

原型是设计输入，不作为生产工程复制来源。生产实现仍采用既定 React 与 .NET Host，不能把原型里的示例定时器、浏览器存储、模拟权限或固定数据当作实现方案。本轮没有提交 Git。
