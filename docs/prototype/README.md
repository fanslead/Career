# Career 前端交互原型

2026-10-14 · 原型 v1。用于评审目标界面与交互，不代表业务功能已上线。

## 打开

- 双击 [index.html](index.html) 即可离线使用，不需要安装依赖。
- [页面图册](gallery.html)汇集桌面与手机页面，点击缩略图可查看原图。
- 界面左下方「页面与流程总览」提供所有主要流程入口；工作台和任务页底部「原型演示场景」可切换首次使用、执行、审批、验收、断线、未知结果、恢复和冲突。
- 「重置示例」只清除这个原型的演示状态。

在支持本地静态服务的环境中也可使用 `python3 -m http.server 4318 --bind 127.0.0.1`，工作目录为本文件所在目录。浏览器访问 `http://127.0.0.1:4318`。

## 覆盖

五个一级入口：工作台、项目、团队、资料、设置。包含独立任务与项目任务、聊天转任务、计划、运行详情、分工、改派、工具许可、固定版本成果、知识与记忆，以及七类设置页面。页面细目与验收映射见 [原型与体验审查](../16-prototype-and-ux-review.md)。

可以输入、切换、保存、返回、取消，操作会改变本地演示状态。任务草稿、非敏感连接输入和表单草稿保留；密码字段不写入持久存储。下载仅生成一份标明“原型示例”的 Markdown 文档。

## 模拟边界

- 所有模型、发送、文件、解析、索引、备份、授权与登录均为本地状态模拟；不执行任何真实后端业务。
- 不要填写真实密钥。文件选择只读取文件名，不读取文件正文或上传。
- 内置研究、研发和经营内容是示例，费用、活动时间、来源与检查数量不是实际测量结果。
- 定时器用于演示“请求已提交 → 执行者确认”；真实实现必须等待服务端确认。
- `localStorage` 仅保存原型演示数据。生产浏览器令牌不得沿用此存储方式。
- 当前交互与截图不是平台、模型、外发和恢复的生产验证证据。

## 文件

- `index.html`、`styles.css`：页面外壳与响应式样式。
- `app.js`：工作台、任务、项目、审批、验收与场景模拟。
- `secondary.js`：团队、知识/记忆和设置。
- `gallery.html`、`review.html`、`screenshots/`：页面图册和浏览器截图。
- `validation.json`：原型级浏览器走查记录。
