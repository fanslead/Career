## 产品定位

**项目文档自述：** Pi 把自己定位为“可自行定制的精简、可扩展 agent harness”，提供交互式 CLI、print/JSON、RPC 与 TypeScript SDK；内建默认能力刻意不含 sub-agent 和 plan mode，扩展和 Pi Packages 提供了自行增配的路线。[README：定位及模式](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/README.md#L15-L21)

**源码结构确认：** 同一仓库现在同时包含 `pi-coding-agent` CLI 和 `pi-durable` 等独立库；不能把下文的 Durable SDK 恢复协议误当作 CLI JSONL 会话本身的实现。[README：包清单](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/README.md#L69-L81) `pi-durable` 自身标为实验性，API 可随发布变更。[pi-durable README](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/durable/README.md#L1-L7)

## 从输入走到工具和完成

**CLI 源码确认：** `AgentSession._startRun()` 把已准备的消息交给 `Agent.prompt()`，之后持续处理恢复、继续和 settle 边界。[agent-session.ts](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/src/core/agent-session.ts#L1831-L1881) 低层循环发起模型响应；若响应带 tool call，则执行工具、追加 tool result，再依据结果进入下一轮，最终发出 `agent_end`。[agent-loop.ts](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/agent/src/agent-loop.ts#L241-L320) 工具名解析、参数校验、`beforeToolCall` 阻断钩子、abort 检查和真正执行的次序在同一调用路径可见。[agent-loop.ts](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/agent/src/agent-loop.ts#L708-L777)

**用户可见状态（项目文档自述 + 源码确认）：** 默认交互界面展示 prompt、响应、tool calls/results/errors；运行时逐项显示工具调用与结果，footer 显示模型、会话、上下文用量和累计用量。[usage.md](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/usage.md#L7-L27) [交互 footer](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/src/modes/interactive/components/footer.ts#L279-L300) CLI 另向终端发出 `working`、`blocked`、`done`、`error`、`idle` 状态，并将提示限制为会话名、对话框标题或错误首行。[program-status-reporter.ts](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/src/modes/interactive/program-status-reporter.ts#L11-L16) [状态转移](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/src/modes/interactive/program-status-reporter.ts#L35-L76)

**Pi Durable SDK 的独立流程（源码确认）：** `submit()` 先在一个提交中接纳输入；空闲会话将其写为 `pi.user`、创建 submission 并启动 generation。[submissions.ts](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/durable/src/harness/submissions.ts#L161-L240) generation 准备 prompt/tool loadout 后提交请求 checkpoint，再调用模型；工具调用成为 generation 拥有的任务，工具 task 校验参数、运行钩子、持久化调用意图后才执行。[generation.ts](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/durable/src/harness/generation.ts#L114-L194) [工具轮及所有权](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/durable/src/harness/generation.ts#L569-L615) [tool task](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/durable/src/harness/tool.ts#L123-L166) 最终 answer 和 submission `done` 在一次提交中落盘；有排队输入时也在边界处处理。[generation.ts](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/durable/src/harness/generation.ts#L537-L567)

## 配置、技能与扩展边界

- **模型配置：** 内建 provider 通过 `/login` 登录、`/model` 选模型；可用 `models.json` 声明兼容 endpoint、模型元数据或 override；需自定义协议/认证时使用 provider extension。会话会记录模型和 thinking level 变更，并在恢复时还原而不改新会话默认值。[models.md](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/models.md#L3-L35) `models.json` provider/model schema 在代码中验证，包括 API、URL、reasoning、上下文窗口、token 上限和采样参数。[model-config.ts](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/src/core/model-config.ts#L32-L78)
- **Skills：** Markdown 指令包，启动时只把名称、描述、路径交给模型；需要时再读取完整 `SKILL.md`，也可通过 `/skill:name` 显式调用。它是指令/资源分发，不是新运行时工具 API。[skills.md](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/skills.md#L3-L7) [加载时机与目录](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/skills.md#L41-L65)
- **Extensions：** TypeScript/JavaScript 可执行模块，可注册工具、命令、事件钩子、provider、MCP server 和状态 UI；在 Pi 进程内运行，获得该 OS 用户的进程权限，因而不是安全沙箱。[extensions.md](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/extensions.md#L1-L8) [扩展能力接口](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/extensions.md#L72-L89)
- **MCP：** 与 Pi 内的扩展代码分离的外部 stdio/streamable-HTTP 工具与资源来源；用户级和项目级分开配置，项目 MCP 受项目 trust 控制。服务器及单个工具可设为 `direct`、`deferred`、`codemode` 或 `hidden`。[mcp.md](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/mcp.md#L1-L3) [作用域和配置](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/mcp.md#L22-L34) [曝光控制](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/src/core/mcp-servers.ts#L38-L78)
- **Pi Packages：** npm/git/本地安装及分发容器，可一起交付 extensions、skills、prompt templates、themes；它是 Pi 自己的包格式。源码中存在 `pi.registerMcpServer()`，MCP 连接生命周期由内建/其他 MCP 扩展处理，而非等同于 Pi Package。[packages.md](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/packages.md#L1-L21) [资源清单](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/packages.md#L42-L72) [MCP registration 边界](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/src/core/mcp-servers.ts#L1-L6)

项目 trust 控制是否从项目加载 settings、MCP、extensions、skills 等资源；文档同时明确它不约束已启用工具的文件/进程访问权限。用户可读到项目资源信任询问，但不可把这个决定视为执行沙箱。[security.md](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/security.md#L27-L55)

## 会话记忆、隔离与协作

- **CLI 的可恢复上下文：** 默认 session 文件按工作目录分组在 `~/.pi/agent/sessions/`；JSONL entry 以 `id`/`parentId` 形成可分支的树。恢复会话时模型取当前 active branch，而非整个文件。[sessions.md](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/sessions.md#L1-L18) [session-format.md](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/session-format.md#L1-L14) [活动分支及上下文](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/sessions.md#L20-L40)
- **持久化与 compaction：** CLI 在 `message_end` 时把 user/assistant/toolResult 写入会话，首次对话时创建文件，随后 append JSONL。[agent-session.ts](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/src/core/agent-session.ts#L1147-L1187) `/continue`、`/resume` 恢复会话；compaction 用摘要替代发送给模型的旧上下文并保留近期消息，不删除原 session entries。[sessions.md](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/sessions.md#L36-L54) 会话格式把 compaction 摘要和 kept boundary 持久化。[session-format.md](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/session-format.md#L123-L147)
- **用户/项目共享范围：** 同一 agent directory 下有用户级 instructions、MCP、skills 和 extensions；项目 `.pi` 资源另有项目级位置，并受 trust 保护。[configuration.md](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/configuration.md#L7-L47) **本次未找到证据：** CLI 默认提供可跨项目语义检索、统一共享的长期记忆库；可确认的是工作目录分组的 session、可发现的上下文文件和 Skills。
- **Subagent 是可选扩展示例，不是内建功能：** 示例工具每次启动单独 `pi` 子进程，参数带 `--mode json -p --no-session`、任务、模型/思考级别及可选 tools/system prompt；因此子 agent 有独立上下文，父 transcript 不作为参数传入，但默认工作目录仍是父 `ctx.cwd`，这不是文件系统隔离。[README 对默认能力的说明](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/README.md#L15-L21) [子进程参数和 cwd](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/examples/extensions/subagent/index.ts#L300-L350)
- **协作与可见状态：** 示例支持单 agent、最多 8 项并行（最多 4 项同时运行）和链式任务；链式把前步输出插入 `{previous}`。默认只发现 user agents；project agents 需明确 scope，在不受信任项目的交互模式下会再次询问。[README：模式/安全默认](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/examples/extensions/subagent/README.md#L55-L97) 并行模式报告完成/运行计数和失败诊断；工具更新实时收集子进程流及用量，TUI 可展开完整任务、工具调用和结果。[README：状态显示](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/examples/extensions/subagent/README.md#L99-L117) [进程事件和更新](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/examples/extensions/subagent/index.ts#L324-L386) [并行状态更新](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/examples/extensions/subagent/index.ts#L616-L685)
- **Durable SDK 的会话/状态边界：** 实验性 `pi-durable` 把 transcript、task、document 分开持久化；agent 选择记录在每个 conversation 的 `pi.agent`，task 与 conversation 有明确 owner。[README：数据模型](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/durable/README.md#L80-L101) 它能用 SQLite/JSONL 存储并 resume 未完成工作；submission 可带 `requestId` 防止重试重复提交。[README：持久恢复](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/durable/README.md#L103-L126) 工具执行意图先提交；恢复时只有“已存策略和当前工具定义都标 safe”才重跑，否则产出可能部分执行的 interrupted 结果。[tool.ts](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/durable/src/harness/tool.ts#L156-L198)

## 可借鉴与不宜照搬

**可借鉴：**

1. 将调用模型可见的工具 loadout、参数校验、执行钩子与结果作为一条可追踪链，UI 与 transcript 共享事件事实，便于重放和诊断。[agent-loop.ts](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/agent/src/agent-loop.ts#L258-L290) [Session 持久化事件](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/src/core/agent-session.ts#L1143-L1198)
2. 让用户级与项目级配置并存，同时对项目可执行资源设加载信任边界；资源描述可延迟加载，减少常驻上下文。[configuration.md](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/configuration.md#L11-L47) [skills.md](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/skills.md#L41-L53)
3. 为长期执行明确区分普通对话持久化和 Durable task：以原子提交、稳定 request ID、任务 checkpoint 和显式 replay policy 处理重启，而不是仅靠恢复提示词推断状态。[Durable admission](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/durable/src/harness/submissions.ts#L161-L240) [任务调度重开](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/durable/src/harness/scheduler.ts#L288-L321)

**不宜照搬：**

1. CLI 明确“不对每次工具调用询问”，且工具以启动 Pi 的 OS 用户权限访问文件和进程；对需要审批或隔离的产品，不应把逐事件可见性当作授权控制。[security.md](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/security.md#L1-L23)
2. 项目 trust 只控制项目资源能否加载，不能限制工具访问范围；extensions 和子进程继承 Pi 的操作系统权限。应将审批与真实文件、网络、凭证边界放在执行层。[security.md](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/security.md#L27-L55) [扩展运行权限](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/docs/extensions.md#L1-L8)

## 可复现的验收思路（本次未执行）

1. 用固定的假模型依次返回 tool call 和最终文本，断言事件顺序为 assistant call → tool start/update/end → toolResult → final assistant/settled；另分别送无效参数、钩子阻断及 abort，确认工具没有误执行、错误可见且队列状态正确。代码锚点：[agent loop](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/agent/src/agent-loop.ts#L258-L320)、[参数验证/阻断](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/agent/src/agent-loop.ts#L708-L777)。
2. CLI 写入一条会话后退出并用 `--continue` 恢复；再制造长上下文触发 compaction，断言活动分支收到摘要与保留尾部、JSONL 原始 entries 仍在。建议复用 `packages/coding-agent/test/agent-session-compaction.test.ts`、`packages/coding-agent/test/session-manager/` 的现有测试分组。
3. 对 Durable SDK 做进程重启故障注入：在工具 intent 提交后、执行结束前终止进程；`replay: "safe"` 工具应按相同参数重放，unsafe 工具应回传 interrupted 而非伪报成功。重复提交相同 `requestId`，断言 submission id 不变且只发生一次 admission。[tool recovery policy](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/durable/src/harness/tool.ts#L168-L198) [requestId 去重](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/durable/src/harness/submissions.ts#L171-L187)。
4. 安装 subagent 示例后分别执行单任务、并行失败、chain 和 Ctrl+C；断言默认 scope 不加载项目 agents、不受信项目会询问、并发上限 4、终端显示进度与失败信息，且 child 没有收到父 transcript。[subagent README](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/examples/extensions/subagent/README.md#L55-L117) [spawn 参数](https://github.com/earendil-works/pi/blob/7efebff189ddc4077b332e1552fff899ed387d28/packages/coding-agent/examples/extensions/subagent/index.ts#L300-L350)。

**本次未找到证据：** 在这个固定提交上实际安装运行子 agent、kill/restart Durable Harness，或验证终端呈现和外部副作用幂等性的运行记录。因此以上是可复现验收方案和代码路径分析，不是运行通过声明。
