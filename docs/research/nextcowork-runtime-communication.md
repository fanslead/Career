# NextCoWork 前端与 Agent Runtime 通信

核查快照：[`AIDotNet/NextCoWork` commit `b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917`](https://github.com/AIDotNet/NextCoWork/commit/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917)。以下按源码调用链描述；不是把 README 的能力清单当作实现证据。

## 本机 Electron 模式

NextCoWork 的桌面 UI 是 Electron `BrowserWindow` 中的 React renderer。README 把 `src/main` 标为 Electron 主进程、`src/preload` 标为 renderer/main bridge、`src/renderer` 标为 React UI；主窗口启用 `contextIsolation`、`sandbox`，并关闭 `nodeIntegration`。[README 项目结构](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/README.md#L71-L80)；[BrowserWindow 安全设置](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/index.ts#L318-L329)

一次对话的主路径是：

1. renderer 的会话 store 先生成 `runId`、登记会话映射，再调用 `startRun`；因此主进程发出的第一批事件回来时，UI 已知道应把它归到哪个会话。[session store](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/renderer/src/stores/session.ts#L283-L340)
2. renderer 服务层把 `startRun` 映射为 `invoke('agent:run', req)`，用 `on('agent:event')` 接事件。`invoke` / `on` 统一走 `window.nextcowork`，而不是组件自行操作频道。[agent service](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/renderer/src/services/agent.ts#L18-L118)；[IPC service](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/renderer/src/services/ipc.ts#L24-L65)
3. preload 是受限 bridge：对 invoke/send/on 频道做运行时白名单检查，通过 `ipcRenderer.invoke/on` 传输，并且不把带 `sender` 的 Electron 事件对象交给 renderer；只暴露 `nextcowork` API。[preload bridge](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/preload/index.ts#L32-L62)；[contextBridge 暴露](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/preload/index.ts#L91-L100)
4. 主进程用 `ipcMain.handle` 注册 typed invoke；`safeHandle` 捕获异常并返回 `{ ok, data }` / `{ ok: false, error }` 信封。`agent:run` 接到 `ipc/agent.startRun`；它先为窗口订阅 run topic，再调用服务启动 run，避免启动与订阅之间丢失首批 token。[handler 注册与错误信封](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/ipc/index.ts#L618-L626)；[safeHandle](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/ipc/index.ts#L941-L961)；[订阅后启动](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/ipc/agent.ts#L96-L109)
5. `main/services/agent.ts` 创建 `RunHandle` / `RunPump`，随后调用默认驱动 `runtime.runAgent`；runtime 用 `getRouter()` 构造 `AgentSession`。[服务启动与 launch](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/services/agent.ts#L454-L483)；[runAgent 驱动](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/runtime.ts#L2477-L2495)；[AgentSession 注入 upstream](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/runtime.ts#L2822-L2833)
6. 模型请求由主进程的 `UpstreamRouter` 发起。`AgentSession` 消费 `upstream.stream(...)` 的事件，并转换/包装为 `AgentEvent`；事件包括文本/思考/工具调用增量、工具边界、交互请求和 run 结束。[上游请求为 HTTP POST/SSE](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/kernel/upstream/router.ts#L716-L730)；[消费上游流并 emit](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/kernel/agent-session.ts#L882-L920)；[AgentEvent 类型](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/shared/agent/event.ts#L31-L54)
7. `RunPump` 把高频文本、思考和工具参数增量最多合到一批 64 条、约 16 ms；结构性事件立即 flush。窗口 registry 依据 `run:<runId>` 订阅关系，用 `WebFrameMain.send` 投递 `agent:event`。这条桌面前端通信是 Electron IPC，不是浏览器 HTTP 或 WebSocket。[RunPump 合批与 agent:event 信封](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/services/agent.ts#L41-L120)；[窗口 topic 投递](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/window/registry.ts#L246-L303)

窗口重载或错过事件时，renderer 用 `agent:attach(runId, sinceSeq)` 取主进程快照补齐；主进程先 flush、订阅，再取快照。run 正文没有订阅者时可以暂停推送，但服务端运行与转录持久化继续，窗口回来后可以 attach 恢复。[attach/快照顺序](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/ipc/agent.ts#L140-L159)；[未订阅时丢推送、保留运行](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/services/agent.ts#L100-L120)

## 审批与停止

工具权限策略位于主进程。需要用户决策时，`InteractionGate` 在主进程保存待决项并 emit `interaction_request`；renderer 的 `InteractionPanel` 订阅事件并刷新列表，用户回应后调用 `agent:respondInteraction`。主进程会校验 interaction 仍待决且该窗口订阅了对应 run，再将答案交回 gate。[InteractionGate 请求与答复](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/kernel/interaction-gate.ts#L65-L135)；[UI 订阅与回应](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/renderer/src/views/chat/InteractionPanel.tsx#L40-L97)；[主进程回应授权检查](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/ipc/agent.ts#L191-L218)

停止整轮 run 走 `agent:abort(runId, cascade)`，main 调用 RunRegistry abort；renderer 等 `run_end` 收敛状态。`agent:unwatch` 只解除当前窗口订阅，不停止任务，两者职责不同。[停止/级联中断](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/services/agent.ts#L569-L577)；[IPC 契约区分 abort 与 unwatch](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/shared/ipc/contract.ts#L706-L713)；[UI 停止路径](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/renderer/src/stores/session.ts#L360-L366)

## 独立设备服务与 Web 模式边界

README 定义的是 macOS / Windows / Linux 桌面 Electron 应用。另有可独立运行的 headless Node 设备服务，可持有数据库与工作区；README 要求 Node 24+，并描述桌面通过证书固定连接与它配对。这是远端执行端，不是一个浏览器 UI/API 前端。[README 设备服务](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/README.md#L35-L45)；[README 项目结构](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/README.md#L71-L80)；[headless 服务说明](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/docs/device-service.md#L1-L7)

选择远端设备后，Electron 主进程仍先接收 renderer 的 Electron IPC；`routeInvoke` / `DeviceBroker` 按共享边界表把 `agent:run`、`agent:abort`、交互回应等操作路由到设备。桌面用 `wss://<device>/device` 建立证书校验连接，remote broker 下发 `agent.start`，再由 `AgentBridge` 订阅 `agent.events` 并转成窗口可接收的 `agent:event`。[Agent 通道归设备侧](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/shared/ipc/boundaries.ts#L174-L182)；[IPC 路由](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/ipc/device.ts#L73-L92)；[设备 WSS 连接与握手](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/device/connector.ts#L50-L92)；[remote Agent 方法及事件桥](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/device/broker.ts#L147-L197)；[AgentBridge 事件转发](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/device/agent-bridge.ts#L31-L85)

远端设备服务复用 `main/services/agent` 与同一套 runtime；网络方法在 `src/agent/server/methods/core.ts` 注册，事件 hub 将 Agent 批次发成设备协议 `agent.events` 帧。当前 desktop broker 明确拒绝远端附件、子代理和计划执行请求，因此不能把所有本地 Agent 功能推定为远端均可用。[设备侧启动 Agent 与 attach](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/agent/server/methods/core.ts#L131-L169)；[设备侧事件帧](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/agent/server/events.ts#L58-L88)；[远端输入能力限制](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/src/main/device/broker.ts#L147-L176)

这份源码快照没有显示普通浏览器访问的 NextCoWork Web 客户端；README 提到的插件可提供 “web apps”，指插件扩展类型，不足以证明产品有浏览器版主 UI。另需注意：该项目实现栈是 TypeScript / Electron / Node，而不是 .NET。[README 插件与应用类型](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/README.md#L17-L19)；[README 开发要求](https://github.com/AIDotNet/NextCoWork/blob/b9f580a6c7dadf5ee37e8f1d7e7c09d10a07b917/README.md#L47-L62)
